## AWS Configuration

- Region: `us-east-1` for all projects
- Named profile: `malek`

```bash
export AWS_PROFILE=malek
aws sts get-caller-identity  # verify before running Terraform or SAM
```

## Gotchas

- **Filename typo:** The Kubernetes script is `kuberentes-config.sh` (not `kubernetes`). Use the actual filename.
- **SSH open to world:** VPC security group allows SSH from `0.0.0.0/0`. Restrict to your IP for real usage.
- **Port 8080 exposed:** VPC SG also opens 8080 (Jenkins). Limit in production.
- **tfstate in git:** State files are currently tracked locally. For team use, move to remote state (S3 + DynamoDB lock).
- **AWS costs:** All Terraform and SAM deployments create real AWS resources. Always run `terraform destroy` or delete the SAM stack when done.
